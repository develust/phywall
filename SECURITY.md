# Security Policy

## Supported versions

Only the latest release of phywall gets security fixes. Update with `phywall update --apply`.

## Reporting a vulnerability

Please do not open a public issue for security problems.

- **Preferred:** use GitHub's private reporting: **Security and quality → Report a vulnerability**.
- **Email:** tech@develust.com, encrypted with our PGP key if you can.
  Fingerprint: `8641 BC59 A857 FF1C DF96  EDD1 9C24 CAA3 2329 DA3D`
  Key: https://keys.openpgp.org/search?q=tech%40develust.com

Please include the phywall version (`phywall version`), what you found and how to reproduce it.
We will confirm we received it, keep you updated, and credit you in the release notes if you wish.

## Scope

- The phywall scripts in this repository
- The contribution API at `api.develust.com/v1/contribute/phywall`
